# Algoritmo Bellman-Ford

Atividade da disciplina de Projeto e Análise de Algoritmos (PAA) com implementação do algoritmo Bellman-Ford em Java.

O projeto apresenta:

- Implementação do algoritmo Bellman-Ford;
- Cálculo do menor caminho em grafos;
- Tratamento de arestas com pesos negativos;
- Detecção de ciclos negativos;
- Análise de complexidade temporal O(V·E);
- Exemplo prático de execução.

Tecnologias utilizadas:
- Java
